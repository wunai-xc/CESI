## 1.2 代码块

围栏代码块支持语言标识、文件名/版本元数据、语法高亮，以及右上角的换行与复制按钮：

```ts filename="src/app/content/posts.ts" runtime=Node runtimeVersion=22 languageVersion=5.9
export const posts = loadPosts();
```

## 1.5 自定义标题 id

下面是带自定义 id 的标题，可以从表格里的链接跳过来。

### 自定义锚点 \{#custom-anchor\}

跳转成功的话，你刚才点的链接就把你带到这个小标题了。

> 表格单元格只解析**行内内容**：块级 markdown（`#`、列表、代码块、定义列表）在里面不生效，
> 想展示真实效果就写 HTML 标签，并且整段必须和这一行在同一行、不能换行。
> 单元格里出现的 `|` 必须转义成 `\|`，否则会被当成列分隔符。

[^1]: 这是一条脚注，会出现在文章末尾的脚注区。
